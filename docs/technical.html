Technical document

Aura technical

Does

  • watcher ingests Claude Code and SDK-trace JSONL into DuckDB raw_events, oldest file first.
  • redact.py scrubs secrets from payload before write; optional SHA-256 content hashing.
  • dbt_worker builds 29 dbt models every cycle; cost priced per model call.
  • snapshot_worker publishes a read-only copy data/read/aura.duckdb every 600 s.
  • frontend serves 13 pages and 12 API handlers on :3000; /observability shows pipeline health.

Doesn't

  • Doesn't change or delete transcripts — logs mounted read-only (/logs/claude:ro).
  • Doesn't authenticate users or manage access — no login, no roles.
  • Doesn't fetch prices — only dbt/seeds/model_pricing.csv.
  • Doesn't use cron or Airflow — dbt runs as a watcher subprocess.
  • Doesn't deploy anywhere — CI checks only; Gemini/Codex adapters not built.

Limitations

  • Dashboard lags: snapshot every 600 s plus dbt cycle (~20 min run, 25 min sleep).
  • One writer: dbt holds _snapshot_lock for its whole run; ingestion waits.
  • Incremental models reprocess only sessions touched in the last 24 h.
  • dbt test failures don't block model refresh (dbt run, not dbt build).
  • One machine, one tenant (local); dbt pool 4000 MB inside a 5 GB container.

Top issues

  1. dim_apps puts a session's full cost under every app it touched (~6x spend) — Confirmed
  2. Tool calls on earlier streamed events miss their turn (~18% of executions) — Confirmed
  3. /apps total sums app, agent and person rows of int_entity_spend (2.24x) — Confirmed
  4. All-time 30-day projection divides by at most 14 days (6.2x) — Confirmed
  5. Verdict POST cannot write: frontend mounts /data read-only — Confirmed
  6. /observability gold-layer ages and row counts always blank — Confirmed
  7. SDK-trace redaction can produce invalid JSON payloads — Confirmed
  8. Range views multiply session turn/tool counts by calls per session — Confirmed
  9. Session Prompts tab discards its enriched fetch — Confirmed
  10. Half-written last line can be skipped by the checkpoint — Not verified

Top issues: full detail in section 15. Status rule: Confirmed = kept after the 2026-11-10 review's verification pass; Not verified = marked plausible or a question there.

9.2 Cost formula with pricing SCD lookup

  • calculated_cost = sum(token bucket × per-Mtok rate) / 1,000,000; sdk_trace uses its reported cost.
INfact_model_calls.sql:41-59

  WHEN c.source = 'sdk_trace' THEN COALESCE(c.reported_cost_usd, 0)
  WHEN mp.model IS NULL THEN NULL
  ELSE ( input  × cost_input_per_mtok
       + output × cost_output_per_mtok
       + ephemeral_5m × cost_cache_write_5m_per_mtok
       + ephemeral_1h × cost_cache_write_1h_per_mtok
       + (cache_creation − 5m − 1h) × cost_cache_write_1h_per_mtok
       + cache_read × cost_cache_read_per_mtok ) / 1000000.0
END
